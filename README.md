# 삼성전자 주가 예측 보고서

삼성전자(005930) 주가를 매일 자동 분석하고, 향후 **1주·2주·1개월의 예상 변동 범위**를 보여주는 보고서 앱입니다.

- **주소**: **https://bigwavecto.github.io/bigwave-stock/**
- **앱처럼 쓰기**: 휴대폰으로 접속하면 "홈 화면에 추가" 안내가 뜹니다. 추가하면 아이콘으로 바로 열리고, 주소창 없이 전체화면으로 보이며, **인터넷이 끊겨도 마지막에 받은 내용을 볼 수 있습니다.** (아이폰은 Safari에서 공유 버튼 → "홈 화면에 추가")
- **매일 자동**: 평일 오후 4시 40분(한국시간)에 GitHub Actions가 시세를 수집하고 예측을 기록합니다. 내 PC가 꺼져 있어도 실행됩니다.
- **방향은 예측하지 않습니다**: "며칠 뒤 얼마가 된다"는 숫자 대신 "얼마나 흔들릴지"의 범위만 제시합니다. 10년치 데이터로 검증한 결과 방향 예측이 *"오늘 가격 그대로"라고 말하는 것보다도 부정확*했기 때문입니다(자세한 근거는 앱 하단 "예측 방법" 참조).
- **임계값 도달 확률**: "앞으로 한 달 안에 −10%에 닿을 확률 72%"처럼, 가격이 아니라 **확률**로 알려줍니다. 이건 검증에서 실제로 예측력이 확인된 영역입니다.
- **예측 성적표**: 과거 예상 범위·확률 예보와 실제 결과가 자동 비교됩니다. 한 번 기록된 예측은 고치지 않으므로 사후 보정 없는 실제 성적입니다.
- **맥락 정보**: 외국인·기관 수급, 시장 동조도, 현재 국면, 실적 발표 일정을 함께 보여줍니다. **전부 "예측 아님"** — 검증에서 예측력이 없다고 확인된 것들이지만 판단 재료로는 쓸모가 있어 사실만 표시합니다.
- **조사 갱신(반자동)**: 전문가 의견·뉴스 동향은 Claude에게 "보고서 갱신"이라고 요청하면 조사 후 반영됩니다. 오래되면 화면 상단에 경고가 뜹니다.

## 자주 하는 질문

**Q. 보고서 내용이 오래됐다는 경고가 떠요.**
Claude Code(또는 Cowork)에서 이 폴더를 열고 "보고서 갱신"이라고 요청하세요. 조사 후 `data/report.json`이 갱신되고, 푸시하면 사이트에 반영됩니다.

**Q. 자동 갱신이 안 도는 것 같아요.**
저장소의 Actions 탭에서 "일일 데이터 갱신" 실행 기록을 확인하세요. 실패(빨간 표시)면 로그를 Claude에게 보여주면 됩니다. 참고: 60일간 저장소에 활동이 없으면 GitHub가 예약 실행을 자동으로 멈추는데, Actions 탭에서 버튼 한 번으로 다시 켤 수 있습니다.

**Q. "닿을 확률"이 무슨 뜻인가요?**
"앞으로 한 달 안에 **한 번이라도** 그 가격을 찍을 확률"입니다. 찍었다가 되돌아와도 도달로 셉니다. 그래서 "한 달 뒤 그 가격일 확률"보다 항상 높게 나옵니다. 방향을 예측하지 않으므로 위아래가 대칭이고, 변동성이 클수록 양쪽 다 올라갑니다.

**Q. 왜 하락 확률이 상승 확률보다 비관적으로 보이나요?**
계산상 위아래가 같은데도 그렇게 느껴진다면, 지난 몇 년 주가가 많이 올랐기 때문입니다. 실제로 지난 10년 검증에서 하락 확률은 다소 높게 나오는 경향이 있었습니다(예보 17.6% vs 실제 11.2%). 이걸 낮춰 잡을 수도 있지만, 그러면 **과거의 상승장을 미래에 그대로 복사하는 셈**이라 일부러 고치지 않았습니다.

**Q. 왜 "5일 뒤 얼마" 같은 숫자가 사라졌나요?**
믿을 수 없는 숫자였기 때문입니다. 10년치로 검증해 보니 그 예측선은 아무 계산도 하지 않는 기준선("며칠 뒤에도 오늘 가격")보다 부정확했고, 오르내림 방향을 맞힌 비율도 47.7%로 동전 던지기보다 낮았습니다. 반도체지수·환율·하이닉스 등 32개 요인을 넣어봐도 마찬가지였습니다. 대신 **변동 폭은 예측이 가능**해서, 그 범위만 남겼습니다. 범위가 넓다는 것 자체가 "지금은 불확실하다"는 정보입니다.

**Q. 로컬에서도 열 수 있나요?**
네. `index.html`을 더블클릭하면 됩니다. 이 경우 시세는 프록시로 불러오고 예측 기록은 그 브라우저에만 저장됩니다. 모든 기기에서 같은 기록을 보려면 Pages 주소로 접속하세요.

**Q. 휴장일은 어떻게 처리되나요?**
주말과 한국 증시 휴장일(광복절 대체휴일 등)은 예측 대상일에서 자동 제외됩니다. 휴장일 목록은 2027년 3월까지 등록되어 있고, 매년 연말에 갱신이 필요합니다(Claude에게 요청).
