# 결정 기록 (ADR)

이 앱에서 **"왜 그렇게 정했나"** 를 모아둔 곳이다. 결정 하나에 파일 하나.

## 왜 따로 두는가

이 프로젝트는 **하지 않기로 한 것**이 유난히 많다. 방향 예측, 하락 확률 보정,
평균가 이격 반영, 3개월 이상 예측 — 전부 "해봤더니 안 됐다"는 검증 결과 위에 서 있다.
근거를 모아두지 않으면 다음 세션이 같은 것을 다시 시도하고 같은 결론에 다시 도달한다.
실제로 지금까지 **48개 요인·8가지 방식**이 검증에서 탈락했다.

CLAUDE.md는 "무엇을 지켜야 하나"(규칙), `.claude/WORKLOG.md`는 "언제 무엇을 했나"(시간순),
여기는 **"왜 그렇게 정했고 무엇이 있어야 되돌릴 수 있나"** 를 담는다.

## 각 문서의 형식

```
상태 / 날짜 / 관련 문서
## 맥락      — 무엇이 문제였나
## 결정      — 무엇으로 정했나
## 근거      — 숫자. 표본 크기와 기간을 반드시 함께 적는다
## 버린 대안 — 검토했으나 채택하지 않은 것과 그 이유
## 되돌리려면 — **무엇을 보여주면 이 결정을 뒤집을 수 있는가**
```

마지막 항목이 핵심이다. 이 프로젝트의 결정은 대부분 "지금 데이터로는 아니다"이지
"영원히 아니다"가 아니다. 뒤집을 조건을 미리 적어두면, 다음에 같은 아이디어가 나왔을 때
**논쟁 대신 측정**으로 끝낼 수 있다.

## 새 ADR을 쓸 때

- 번호는 이어서 붙인다. 이미 쓴 문서의 번호를 재사용하지 않는다.
- 결정이 뒤집히면 **기존 문서를 지우지 말고** 상태를 `대체됨 → ADR NNN`으로 바꾸고
  새 문서를 쓴다. 뒤집힌 이유가 다음 사람에게 가장 중요한 정보다.
- 근거에 숫자를 넣을 수 없으면 그건 아직 결정이 아니라 의견이다.
