# ADR 002 — 검증 상수는 종목마다 다시 계산한다

- **상태**: 확정 · 구현 완료
- **날짜**: 2026-08-13
- **관련**: CLAUDE.md 「여러 종목 구조」, `.claude/skills/add-symbol/SKILL.md` 1단계, `data/symbols.json`

## 맥락

앱은 화면에 여러 검증 수치를 직접 보여준다 — "신고가 부근에서는 한 달 안에 10% 오른 적이
41.7%였어요", "크게 오른 날의 84%는 시장 전체가 오른 날이었어요" 같은 문장이다.

종목이 하나(삼성전자)일 때는 이 값들이 그냥 HTML에 박혀 있었다.
SK하이닉스를 추가하면서, **박힌 값을 그대로 두고 종목만 바꿔 보여줄 수 있는지**가 문제가 됐다.
가장 편한 길이었고, 겉보기에는 아무 문제가 없었다.

## 결정

**종목별 검증 상수를 `data/symbols.json`의 `stats`에 종목마다 따로 저장한다.**
앱과 검증 스크립트 모두 이 파일 하나를 읽는다.

종목을 추가할 때는 **그 종목의 10년 데이터로 상수를 다시 계산**한다
(`node scripts/research/symbol_stats.js`). 이것이 `add-symbol` 스킬의 1단계이고,
건너뛰면 **화면이 거짓말을 한다.**

## 근거

같은 방법으로 하이닉스 10년치를 다시 돌렸더니 **결론이 반대로 나오는 항목이 있었다.**

| 항목 | 삼성전자 | SK하이닉스 | 차이 |
|---|---|---|---|
| 신고가 부근 → 한 달 내 +10% | **41.7%** (그 외 17.3%) | **40.2%** (그 외 35.5%) | 삼성은 2.4배, 하이닉스는 **사실상 차이 없음** |
| 크게 오른 날 중 코스피 동반 | 84% | 69% | 하이닉스는 혼자 움직이는 날이 2배 |
| 10년 변동성 | 34% | 46% | 1.35배 |
| 실적 주간 변동 배수 | 1.11 | 1.07 | |
| 10년 상승 배수 | 8.6배 | 48.2배 | 5.6배 |
| 크게 오른 날 수 (10년) | 43일 | 111일 | 2.6배 |

숫자만 다른 게 아니라 **문장의 결론이 뒤집힌다.**

- 삼성 국면 카드: "오르는 쪽으로 기울었어요"
- 하이닉스 국면 카드: "별로 다르지 않았어요"
- 삼성 시장 카드: "대부분 시장에서 와요"
- 하이닉스 시장 카드: "혼자 움직이는 날도 적지 않아요"

삼성 값을 복사했다면 하이닉스 화면은 **"신고가 부근에서는 오를 확률이 2.4배"** 라고
말했을 것이다. 실제로는 1.13배로 의미가 없다.

구간 보정 배수도 고정 1.05에서 종목별 산출값 `z1`로 바꿨다(현재 두 종목 모두 1.04).

## 버린 대안

| 대안 | 왜 버렸나 |
|---|---|
| 삼성 값을 전 종목 공통으로 사용 | 위 표대로 결론이 뒤집힌다. 가장 위험한 종류의 버그 — **틀려도 화면에 티가 안 난다** |
| 업종 평균값 사용 | 두 종목 다 반도체인데도 이만큼 다르다. 업종으로 묶을 근거가 없다 |
| 수치를 아예 빼고 정성 문장만 표시 | 검증 결과를 보여주는 것이 이 앱의 존재 이유다. 정보량을 줄이지 않는다는 문체 규칙과도 충돌 |
| 실행 시점에 앱이 직접 계산 | 10년치 원자료를 브라우저로 내려받아야 한다. 데이터 크기·속도 모두 부담 |

## 되돌리려면

이 결정은 사실상 되돌릴 대상이 아니다. 다만 **항목 단위**로는 예외를 둘 수 있다.

어떤 상수를 공통값으로 쓰려면:

1. 등록된 **모든 종목**에서 그 값의 차이가 화면 문구를 바꾸지 않을 만큼 작아야 한다
   (예: `earnings` 1.11 vs 1.07은 둘 다 "실적 주간에는 조금 더 흔들려요"로 같은 문장이 된다)
2. 종목이 늘어나도 유지되는지 재확인해야 한다 — 종목 3개까지의 일치는 우연일 수 있다
3. 공통화하는 순간 `symbols.json`에서 그 항목이 사라지므로, **왜 공통이어도 되는지**를
   여기 ADR에 추가로 적어야 한다

반대로, 새 종목을 추가할 때 **상수 재계산을 건너뛰는 것은 어떤 이유로도 허용하지 않는다.**
급하면 그 종목을 추가하지 않는 쪽이 맞다.
