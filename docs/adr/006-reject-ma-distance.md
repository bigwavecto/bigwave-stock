# ADR 006 — 평균가 이격을 범위 계산에 넣지 않는다

- **상태**: 확정 · 모델 변경 없음
- **날짜**: 2026-08-14
- **관련**: [ADR 001](001-drop-direction-forecast.md), `scripts/research/section_audit2.js`, `scripts/research/band_improve.js`

## 맥락

로드맵 2-1(화면 요소 검증)에서 각 지표가 실제로 무언가를 예측하는지 두 종목 10년치로 쟀다.
잣대는 둘뿐이었다.

1. 이후 **수익률**을 예측하는가 → 앱 입장([ADR 001](001-drop-direction-forecast.md))과 충돌하거나, 대단한 발견
2. 이후 **변동성**을 예측하는가 → 범위 계산에 기여하므로 남길 근거

여기서 **평균가 이격**(현재가가 3·6개월 평균가에서 얼마나 떨어져 있는지, 부호 없는 거리)이
2번에서 강하게 걸렸다. 그동안 검증에서 살아남은 것이 거의 없었기 때문에 유력한 후보로 보였다.

## 결정

**모델을 그대로 둔다.** 평균가 이격을 범위(밴드) 계산에 넣지 않는다.

## 근거

### 통계적으로는 확실히 유의했다

| 검사 | 결과 |
|---|---|
| 이후 변동성과의 상관 (IC) | **0.63** |
| t값 | **10.95** |
| 혼합변동성을 통제한 뒤 잔차에서 | t = **3.8 ~ 5.1** (두 종목 모두) |

혼합변동성으로 설명되고 남은 부분에서도 신호가 남았다.
여기까지만 보면 "범위 계산에 넣자"가 자연스러운 결론이다.

### 그런데 실제로 넣어보니 화면이 나빠졌다

워크포워드로 밴드에 반영해 본 결과:

| | 결과 |
|---|---|
| 구간 적중률이 목표(80%)에 가까워진 경우 | **6개 중 1개** |
| 목표에서 더 멀어진 경우 | **6개 중 5개** |
| 평균 범위 폭 | **약 11% 넓어짐** |

즉 **폭만 넓어지고 적중률은 나빠졌다.** 범위 예측에서 폭을 넓히면 적중률은
저절로 올라가는 것이 정상인데, 그조차 되지 않았다.
(폭을 넓혀 얻은 적중률은 개선이 아니다. "내일 주가는 0원~무한대"는 100% 적중한다.)

### 이 프로젝트에서 반복 확인된 원칙

> **통계적으로 유의 ≠ 화면이 나아짐**

같은 일이 수급 검증에서도 있었다 — 기관 순매수는 t = 3.35~3.70으로 유의했지만
밴드에 넣으면 **조건 없이 전체를 ×1.05 하는 것보다 못했다.**

다음에 "이 지표 상관 높은데 넣자"는 제안이 나오면,
상관계수와 t값이 아니라 **실제 구간 적중률과 평균 폭**으로 확인시킬 것.

## 같이 판정한 것들

| 요소 | 판정 |
|---|---|
| RSI(14) | ❌ 예측력 없음 (t의 절댓값 < 1.7) |
| 1개월 평균가 대비 | ❌ 예측력 없음 |
| **3·6개월 평균가 이격** | 🟡 **변동성 상관 큼, 그러나 범위 개선 실패** → 미채택 |
| 3개월 고저 **위치** | ❌ 잔차에서 무의미 (t = 0.95 / 1.25) |
| "지금 분위기" 배지 | ❌ [ADR 007](007-remove-mood-badge.md)로 분리 |
| 예상 범위·확률·성적표·참고 정보 | ✅ 이미 검증됨, 유지 |
| 증권사 목표가 | ⚪ 과거 컨센서스가 없어 **검증 불가** |

## 버린 대안

| 대안 | 왜 버렸나 |
|---|---|
| 이격을 밴드 배수에 곱한다 | 위 결과. 6개 중 5개에서 적중률 악화 |
| 이격이 클 때만 조건부로 적용 | 조건을 붙이면 표본이 줄고, 어떤 임계값을 고를지가 다시 표본 맞추기가 된다 |
| 이격을 혼합변동성 대신 사용 | 혼합변동성 쪽이 이미 적중률 80.2~80.5%를 낸다. 검증된 것을 미검증으로 바꿀 이유가 없다 |
| 화면에는 남기고 모델에만 안 넣는다 | 화면에 남기는 것은 별개 문제다. **방향 해석 문구**(“평균보다 높아요 → 조정 가능성”)는 근거가 없으므로 제거한다(로드맵 2-2) |

## 되돌리려면

평균가 이격을 밴드에 넣으려면 **통계량이 아니라 결과**를 보여야 한다.

1. 워크포워드 구간 적중률이 **80%에 더 가까워질 것** — 두 종목, 세 기간(1주·2주·1개월) 모두
2. **평균 범위 폭이 넓어지지 않을 것** (같거나 좁아야 한다)
3. 1·2를 동시에 만족할 것 — 하나만 되는 것은 폭·적중률 맞바꾸기다
4. 표본을 시기별로 쪼개도 유지될 것

혼합변동성 채택 때가 정확히 이 기준을 통과한 사례다 —
**같은 폭에 적중률만 75.8% → 77.8%.** 그런 것만 채택한다.
