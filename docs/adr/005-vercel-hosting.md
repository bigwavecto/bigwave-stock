# ADR 005 — GitHub Pages에서 Vercel + stock.bigwave.im으로 옮긴다

- **상태**: 확정 · 구현 완료
- **날짜**: 2026-08-13
- **관련**: CLAUDE.md 「배포 정보」, `vercel.json`

## 맥락

처음에는 GitHub Pages에 올렸다(`bigwavecto.github.io/bigwave-stock/`).
빌드가 없는 단일 HTML 앱이라 잘 맞았고, 실제로 문제없이 작동했다.

세 가지가 걸렸다.

1. **주소가 길고 기억하기 어렵다.** 휴대폰에서 남에게 알려주기 나쁘다.
2. **저장소를 반드시 공개로 유지해야 한다.** 무료 플랜에서 Pages를 쓰는 조건이다.
   비공개로 바꾸는 순간 사이트가 내려간다.
3. **응답 헤더를 제어할 수 없다.** PWA로 전환하면서
   `manifest.webmanifest`의 MIME 타입과 서비스 워커·데이터 파일의 캐시 정책을
   직접 지정해야 했는데, Pages에서는 방법이 없다.

3번이 결정적이었다. `.webmanifest`가 잘못된 MIME으로 나가면 **"홈 화면에 추가"가 아예 안 되고**,
`sw.js`가 캐시에 갇히면 사용자가 옛 화면에서 빠져나오지 못한다.

## 결정

**Vercel(Hobby)에 배포하고 `stock.bigwave.im`을 연결한다.** GitHub Pages도 당분간 함께 둔다.

- 빌드 없음. `vercel.json`은 **헤더만** 잡는다.
- DNS는 **후이즈에 그대로 두고** 서브도메인 `stock`만 CNAME으로 Vercel에 연결한다.
- 데이터 갱신 커밋마다 Vercel이 자동 재배포한다(기존 Actions 워크플로 그대로).

### `vercel.json`이 잡는 헤더와 각각의 이유

| 대상 | 설정 | 이유 |
|---|---|---|
| `manifest.webmanifest` | `Content-Type: application/manifest+json` | Vercel 기본 MIME 목록에 `.webmanifest`가 없을 수 있다. 틀리면 홈 화면 추가가 안 된다 |
| `sw.js`, `index.html`, `data/` | `max-age=0, must-revalidate` | 매일 갱신되는 내용. 특히 서비스 워커가 캐시에 갇히면 복구가 어렵다 |
| `icons/`, `vendor/` | 1년 캐시 | 내용이 바뀌지 않는다 |

## 근거

| | GitHub Pages | Vercel Hobby |
|---|---|---|
| 비용 | 0원 | 0원 (비상업용) |
| 커스텀 도메인 | 가능 | 가능 |
| 응답 헤더 제어 | **불가** | `vercel.json`으로 가능 |
| 저장소 공개 강제 | **필요** | 불필요 |
| 배포 트리거 | Pages 빌드 | git push 자동 |
| 빌드 시간 | 수십 초 | 수 초 (빌드 없음) |

저장소 공개 강제가 풀린 것도 부수 효과로 컸다.
Pages 때문에 공개를 유지해야 했고, 그 전제 위에서
**"저장소에 개인정보·키·이메일을 커밋하지 않는다"** 는 규칙이 나왔다.
Vercel로 옮긴 뒤에도 이 규칙은 그대로 지킨다 — Pages를 아직 살려두고 있고,
규칙 자체가 옳기 때문이다.

## 버린 대안

| 대안 | 왜 버렸나 |
|---|---|
| Pages 유지 + 커스텀 도메인만 연결 | 헤더 제어 문제(핵심)가 그대로 남는다 |
| 네임서버를 Vercel로 이전 | **`bigwave.im`과 `www`가 다른 서버에서 별도 서비스 중이라 같이 죽는다.** Vercel 화면의 "Vercel DNS" 탭이 그것이니 누르지 말 것 |
| Netlify / Cloudflare Pages | 기능상 차이가 없다. GitHub 연동 경험이 이미 있는 쪽을 택했다 |
| 직접 서버 운영 | 정적 파일 하나에 서버를 두는 것은 과하다. 운영 부담만 는다 |
| Pages를 즉시 폐기 | 되돌릴 곳을 남겨두는 편이 낫다. 유지 비용이 0이다 |

## 알아둘 제약

- **Vercel Hobby는 비상업용 전용이다.** 이 앱으로 수익이 발생하기 시작하면
  Pro(월 $20)로 올려야 한다. 로드맵 3·5·6번(로그인·랜딩·관리자)이 이 선을 건드릴 수 있다.
- `vercel.json`에 **주석을 넣지 말 것.** `"//"` 같은 키를 쓰면 스키마 검사에서
  `should NOT have additional property` 오류로 배포가 거부된다(실제로 겪었다).
- 저장소를 비공개로 바꿔도 Vercel은 유지된다. 그 경우 GitHub Pages만 죽는다.

## 되돌리려면

Pages로 돌아가려면 **헤더 문제를 다른 방법으로 해결**해야 한다.
현실적으로는 PWA를 포기하는 것이 유일한 길이므로, 사실상 되돌리지 않는다.

Vercel을 떠나야 하는 상황(요금제·정책 변경 등)이 오면 판단 기준은 하나다 —
**응답 헤더를 파일로 선언할 수 있는가.** 그것만 되면 이전 대상이 된다.
DNS는 CNAME 한 줄만 바꾸면 되므로 이전 비용 자체는 작다.
