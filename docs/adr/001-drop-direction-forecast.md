# ADR 001 — 방향 예측을 폐기하고 범위 예측으로 전환

- **상태**: 확정 · 구현 완료 (모델 v2)
- **날짜**: 2026-08-13
- **관련**: CLAUDE.md 「핵심 규칙 1」, [ADR 004](004-no-long-horizon.md), [ADR 006](006-reject-ma-distance.md)
- **근거 원본**: 검증 보고서 https://claude.ai/code/artifact/db598626-dc86-4fea-b56b-2f47b1dd6b6d

## 맥락

초기 모델(v1)은 며칠 뒤 **가격이 얼마가 될지**를 맞히려 했다.
세 항의 가중 합으로 하루 변화율(드리프트)을 만들고 상한 ±1.5%를 걸었다.

```
드리프트 = 모멘텀 0.4 + 평균회귀 0.3 + 증권사 컨센서스 0.3
```

사용자가 "5일 예측이 실제로 타당한지 조사하라"고 요청했다.
그때까지 이 모델은 **한 번도 검증된 적이 없었다.**

## 결정

**방향(중심값)을 예측하지 않는다.**

- 중심값 = **오늘 종가 그대로**(수평선)
- 범위 = `Z80 × 혼합변동성 × √t`
  - `Z80 = 1.2816 × z1` (z1은 종목별 두꺼운 꼬리 보정, 현재 두 종목 모두 1.04)
  - 혼합변동성 = 20·60·250일 분산의 **평균의 제곱근**
- 20거래일치를 만들어 앱에서 1주/2주/1개월로 잘라 쓴다

앱의 입장을 한 문장으로: **"얼마가 될까"는 못 맞히고, "얼마나 움직일까"는 맞힐 수 있다.**

## 근거

10년치(2016-08 ~ 2026-08, 2,446 거래일) 워크포워드 백테스트.
매 거래일 **그날까지의 데이터만** 써서 예측하고 실제와 대조했다.
비교 기준(baseline)은 랜덤워크 — "며칠 뒤에도 오늘 가격"이라고 말하는 방식.

### 1. 방향 예측은 전 기간에서 랜덤워크에 졌다

| 기간 | 랜덤워크 대비 오차 비율 | 판정 |
|---|---|---|
| 1일 | 1.008배 | 패 |
| 5일 | 1.031배 (3.34% vs 3.24%) | 패 |
| 1개월 | — | 패 |
| 6개월 | 1.267배 | 패 |

t = 2.4 ~ 4.2 로 **통계적으로 유의하게** 나빴다. 우연이 아니다.

- 방향 적중률 **47.7%** (동전 던지기보다 낮다)
- 예측 방향과 실제 수익의 상관 **−0.08** (반대로 맞물려 있었다)

### 2. 원인은 모멘텀 항이었다

어느 날 예측 +4.1%를 뜯어보니 **111%가 모멘텀에서** 나왔고(전날 +4% 급등의 연장),
나머지 두 항은 서로 상쇄됐다. 그런데 일간 모멘텀은 **약한 역상관**이다.
즉 모델은 정확히 반대편에 베팅하고 있었다.

같은 모델로 기간만 늘리면 3개월 예측이 **+62.3%** 가 됐다.
"예측 기간을 늘려달라"는 요청을 v1 위에 붙이면 안 됐던 이유다.

### 3. 정보는 이미 가격에 들어 있다 (결정적 대비)

같은 요인 집합으로,

| | 설명력 |
|---|---|
| **같은 날** 등락 설명 | R² **70.5%** |
| **하루 뒤** 등락 예측 | R² **2.3%** |
| 코스피와의 상관 (같은 날 → 하루 뒤) | 0.828 → **−0.094** |

무슨 일이 벌어졌는지는 설명할 수 있지만, 무슨 일이 벌어질지는 알 수 없다.

### 4. 변동성은 반대로 예측된다

구간 계산 4가지를 비교했더니 **20·60·250일 혼합**이 기존과 **같은 폭에 적중률만 높았다**
(1개월 구간 적중률 75.8% → 77.8%). 폭을 넓히지 않고 얻은 개선이라 바로 채택했다.

여기에 두꺼운 꼬리 보정(× 1.04~1.05)을 더해 최종 적중률 **80.5 / 80.3 / 80.2%** (목표 80%).

## 버린 대안

| 시도 | 결과 |
|---|---|
| 점추정 7가지 변형 (축소·부호반전·평균회귀만·과거평균 등) | **전부** 랜덤워크 미달 |
| 외부 요인 32개 (하이닉스·SOX·TSMC·나스닥·코스피·원달러·VIX + 가격지표) | 5일 1/32 유의(우연 기대치 1.6개), 1개월 **0/32** |
| 상승 확률(%) 예보 | BSS 전부 음수, AUC 0.40~0.51. "75% 상승"이라 말한 날의 실제 상승률이 5일 51% · 1개월 42%. 5분위 정렬도 순서 없음/역전 |
| 수급(외국인·기관) 16개 지표 | [ADR 003 참조]. 기관만 유의했으나 2023년 이후 소멸, 독립 사건 15건뿐 |
| 신고가 규칙을 예측선에 반영 | 1.000 / 1.011 (개선 없음) |
| 비대칭 밴드 | 적중률 하락 |

**부호를 뒤집어도 이기지 못했다**는 점이 중요하다.
모델이 반대로 맞물려 있었다면 뒤집으면 이겨야 하는데, 그러지 않았다.
신호 자체가 없다는 뜻이다.

## 되돌리려면

방향 예측을 되살리려면 다음을 **전부** 보여야 한다.

1. 워크포워드(그 시점까지의 데이터만 사용) 오차 비율이 **랜덤워크 대비 1.0 미만**
2. **두 종목 모두**에서 성립
3. **여러 기간**(1일·5일·1개월)에서 성립 — 한 기간만 되는 것은 우연이다
4. 표본을 시기별로 쪼개도(2016~2019 / 2019~2022 / 2022~2025 / 2025~) 부호가 유지
5. **독립 사건 수**를 명시 — 250일이 15건의 독립 사건인 경우가 실제로 있었다
6. 여러 지표를 훑었다면 **다중 비교 보정** (32개 중 1개 유의는 우연 기대치와 같다)

> 새 아이디어를 시도하기 전에 검증 보고서를 먼저 읽을 것.
> 지금까지 48개 요인·8가지 방식이 실패했다. 49번째도 같은 방식으로 실패할 가능성이 높다.
