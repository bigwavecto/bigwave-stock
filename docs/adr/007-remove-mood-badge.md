# ADR 007 — "지금 분위기" 배지를 화면에서 뺀다

- **상태**: 확정 · 구현 완료
- **날짜**: 2026-08-14 (결정), 2026-08-14 (구현)
- **관련**: [ADR 001](001-drop-direction-forecast.md), [ADR 006](006-reject-ma-distance.md), `scripts/research/section_audit.js`

## 맥락

화면 상단에 원형 배지가 있다. 여러 지표를 점수화해 합산한 뒤
**좋음 / 조금 좋음 / 보통 / 조심** 네 등급으로 보여준다(`renderSummary`).

이 배지는 앱에서 **가장 눈에 먼저 들어오는 요소**다. 원형이고, 크고, 맨 위에 있다.
그런데 [ADR 001](001-drop-direction-forecast.md)에서 방향 예측을 폐기한 뒤에도
이 배지만 그대로 남아 있었다. v2 전환 때 drift 항목만 빼고 나머지 점수 로직은 살렸기 때문이다.

## 결정

**배지와 점수 로직 전체를 제거한다.**

같이 제거하는 것(전부 근거 없는 방향 해석):

- 차트 지표의 방향 해석 문구 ("짧게 보면 오름세" 등)
- RSI 해석
- 3개월 고저 **위치** 해석

배지가 있던 자리는 비우지 않는다. 상단은 시선이 먼저 닿는 자리다.
방향 판정 대신 **"지금 얼마나 흔들리는지"** — 검증된 정보 — 를 보여준다.

## 근거

### 1. 등급이 이후 수익률과 무관하다

두 종목 10년치로, 배지 등급별 **20거래일 뒤** 결과를 집계했다.

| 배지 | 삼성전자 | SK하이닉스 |
|---|---|---|
| 좋음 | +2.35% (상승 54%) | +2.22% (상승 52%) |
| 조금 좋음 | +2.72% (상승 53%) | +5.99% (상승 59%) |
| 보통 | +0.70% (상승 53%) | +2.47% (상승 51%) |
| 조심 | 표본 부족 | **+8.28% (상승 69%)** ← 가장 좋음 |

- 삼성에서도 "좋음"이 "조금 좋음"보다 **나빴다** (등급 순서와 결과가 어긋난다)
- 하이닉스에서는 **순서가 완전히 뒤집혔다.** "조심"일 때가 가장 많이 올랐다
- 상승 확률은 전 등급이 51~59%로, 등급과 무관하게 그냥 **상승장이었다는 사실**만 보여준다

### 2. 구성 요소 하나하나가 이미 탈락했다

배지 점수를 만드는 재료가 [ADR 006](006-reject-ma-distance.md) 검증에서 전부 떨어졌다.

- RSI(14): 예측력 없음
- 1개월 평균가 대비: 예측력 없음
- 3개월 고저 위치: 잔차에서 무의미 (t = 0.95 / 1.25)
- 평균가 이격: 변동성과는 상관 있으나 밴드 개선 실패

**아무것도 예측하지 못하는 재료를 합산해도 예측이 되지 않는다.**

### 3. 앱이 자기 문장과 모순된다

배지 두 줄 아래에 이렇게 쓰여 있다.

> 이 앱은 오를지 내릴지는 맞히지 않아요

바로 위에서 "좋음/조심"으로 방향을 판정해 놓고 있다.
사용자는 큰 원형 배지를 먼저 읽고, 작은 글씨 경고는 읽지 않는다.
**화면에서 가장 강한 주장이 앱의 공식 입장과 반대**인 상태다.

## 버린 대안

| 대안 | 왜 버렸나 |
|---|---|
| 배지를 남기고 "참고용" 문구를 붙인다 | 경고 문구는 읽히지 않는다. 원형 배지의 시각적 무게를 이길 수 없다 |
| 배지 산식을 고쳐 예측력을 만든다 | 재료가 전부 탈락했다. 새 재료를 찾는 것은 49번째 요인 시도이며 [ADR 001](001-drop-direction-forecast.md) 조건을 먼저 통과해야 한다 |
| 배지만 빼고 자리를 비운다 | 상단 요약은 시선이 먼저 닿는 자리다. 비우면 앱이 무엇을 말하는지 첫인상이 사라진다 |
| 배지를 "변동성 등급"으로 이름만 바꾼다 | 같은 점수 로직을 이름만 바꿔 남기는 것. 새 표시는 **변동성 데이터에서 새로 계산**해야 한다 |

## 되돌리려면

방향을 판정하는 종합 배지를 되살리려면:

1. 등급별 이후 수익률이 **단조롭게 정렬**될 것 — 좋음 > 조금 좋음 > 보통 > 조심
2. **두 종목 모두**에서 같은 순서일 것 (지금은 하이닉스가 완전히 역전이다)
3. 각 등급의 **독립 사건 수**를 명시할 것 — "조심"은 삼성에서 표본 부족이었다
4. 표본을 시기별로 쪼개도 순서가 유지될 것
5. 통과하더라도, 화면의 "오를지 내릴지는 맞히지 않아요" 문구와
   **어느 쪽을 바꿀지 먼저 정할 것**

> 5번이 실질적으로 가장 어렵다. 배지를 되살린다는 것은
> 이 앱이 방향을 예측하는 앱이 된다는 뜻이고, 그것은 ADR 001을 뒤집는 일이다.

## 실제로 무엇으로 바꿨나 (2026-08-14 구현)

원형 표시는 남기고 내용만 바꿨다. **"지금 흔들림 · 평소의 N배"** —
지금 흔들림(예상 범위를 만든 바로 그 값)을 그 종목의 지난 10년 평균과 비교한 배수다.

| | 예전 | 지금 |
|---|---|---|
| 보여주는 것 | 좋음 / 조금 좋음 / 보통 / 조심 | 평소의 3.0배 |
| 계산 근거 | RSI·평균가·목표가 점수 합산 | `blendedVol`(범위 계산에 쓰는 값) ÷ `stats.vol10y` |
| 검증 여부 | 등급과 결과가 무관 | 범위 적중률 80%로 검증된 값 |
| 색 | 등급별로 초록→빨강 | **바꾸지 않음** |

**색을 등급에 따라 바꾸지 않는 것도 결정이다.** 흔들림은 좋고 나쁨이 아니라 크고 작음이다.
빨갛게 칠하는 순간 "조심하라"는 신호가 되어 없앤 배지가 이름만 바꿔 돌아온다.

같이 한 것 (로드맵 2-2):

- `차트 지표` + `참고 정보` → **"지금 상황"** 한 카드로 합침 (둘 다 "예측 아닌 사실")
- 평균가·최저·최고 태그를 방향 해석에서 **거리 사실**로 교체
  ("짧게 보면 오름세" → "▲ 지금 가격이 10.1% 위")
- RSI 태그를 관용적 호칭 설명으로만 축소, `techVerdict`(고저 위치 해석) 제거
- 흔들림 행에만 **"✅ 이 값만 위 예상 범위 계산에 쓰여요"** 를 붙여,
  검증된 값과 참고용 숫자를 표 안에서 구분
- 카드 위에 묶음 제목 4개 추가 — *확인한 것 / 벌어지고 있는 일 / 사람들이 보는 것 / 계산 방법*
