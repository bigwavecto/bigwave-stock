# ADR 004 — 3개월을 넘는 가격 예측을 제공하지 않는다

- **상태**: 확정 · 구현 완료
- **날짜**: 2026-08-13
- **관련**: [ADR 001](001-drop-direction-forecast.md)
- **근거 원본**: 검증 보고서 https://claude.ai/code/artifact/db598626-dc86-4fea-b56b-2f47b1dd6b6d

## 맥락

"5일만 보여주지 말고 6개월·1년도 보여달라"는 요구는 자연스럽다.
투자 판단은 보통 그 정도 기간에서 이뤄지고, 증권사 목표주가도 6~12개월 기준이다.

기술적으로도 간단해 보인다 — 모델이 `√t`로 범위를 벌리므로 `t`만 키우면 그만이다.

## 결정

- **예측선(범위)**: 20거래일까지만 만든다. 앱은 1주 / 2주 / 1개월로 잘라 보여준다.
- **임계값 도달 확률**: 1주 / 1개월 / **3개월**까지.
- 6개월·1년 가격 예측은 **제공하지 않는다.**

## 근거

### 1. 기간이 길수록 랜덤워크에 더 크게 진다

워크포워드 오차 비율(1.0 = 랜덤워크와 동률, 낮을수록 좋음):

| 기간 | 비율 |
|---|---|
| 1일 | 1.008 |
| 5일 | 1.031 |
| 6개월 | **1.179** |
| 1년 | **1.374** |

방향 예측을 걷어낸 v2에서도 **불확실성 자체**가 기간과 함께 커진다.
길게 볼수록 좋아지기는커녕 반대다.

### 2. 장기 지표의 유의성은 표본 착시다

1년 기준 지표 몇 개는 t = −2.2 ~ −2.9 로 유의해 보였다.
그런데 **독립 표본이 7개뿐**이다.

10년 = 2,446 거래일이지만, 1년 앞을 보는 예측에서 겹치지 않는 구간은 10개도 안 된다.
매일 한 번씩 재면 2,446개처럼 보이지만 서로 거의 같은 사건이다.
t값 계산에 2,446을 넣으면 유의성이 부풀려진다.

같은 함정이 수급 검증에서도 있었다 — 경보일 250일이 알고 보니 **독립 사건 15건**이었고
그중 188일이 2021~22 하락장 한 시기에 몰려 있었다.

### 3. 3개월까지만 남긴 이유

임계값 도달 확률은 **가격이 아니라 변동 폭**을 쓰는 계산이고,
이 프로젝트에서 유일하게 양의 예측력(BSS +0.04 ~ +0.18)을 낸 부분이다.
3개월(60거래일)은 10년에서 40개 이상의 독립 구간이 나와 채점이 가능하다.
6개월부터는 독립 구간이 20개 아래로 떨어져 채점 자체를 믿기 어렵다.

## 버린 대안

| 대안 | 왜 버렸나 |
|---|---|
| v1 모델의 기간만 늘린다 | 3개월 예측이 **+62.3%** 가 됐다. 모멘텀 항이 기간에 비례해 누적된다 |
| 증권사 목표주가를 장기 중심값으로 쓴다 | 과거 시점 컨센서스 시계열이 없어 **검증 자체가 불가능**하다. 검증 못 한 것을 화면에 올리지 않는다 |
| 범위만 √t로 늘려 1년까지 표시 | 1년 범위는 ±50%를 넘는다. 정보로서 아무 쓸모가 없고, 화면에 있다는 이유만으로 신뢰를 얻는다 |
| "참고용"이라 적고 표시 | 경고 문구는 읽히지 않는다. 표시하지 않는 것이 유일하게 확실한 방법이다 |

## 되돌리려면

장기 예측을 넣으려면:

1. 해당 기간에서 워크포워드 오차 비율이 **1.0 미만**, 두 종목 모두
2. **독립 표본 수를 명시** — 겹치는 구간을 세지 않는다.
   최소 20개 이상의 독립 구간이 필요하다
3. 표본을 시기별로 쪼개도 부호가 유지될 것
4. 범위 예측이라면 구간 적중률이 목표(80%)에 **더 가까워질 것** —
   폭만 넓혀서 적중률을 올리는 것은 개선이 아니다 ([ADR 006](006-reject-ma-distance.md) 참조)

> 데이터가 10년뿐이라는 것이 근본 제약이다.
> 20년·30년 데이터를 확보하면 이 조건 중 2번이 처음으로 충족 가능해진다.
